## Official-source observations (retrieved 2026-08-01)

### Stripe

- [Testing](https://docs.stripe.com/testing) requires account sandbox access and a sandbox secret key. The intended integration must use a restricted key limited to its PaymentIntent resources. Test fixtures do not prove the account can create a PaymentIntent.
- [Webhook signature verification](https://docs.stripe.com/webhooks/signature) requires the unmodified raw request body, `Stripe-Signature` header, and endpoint-specific signing secret. A registered endpoint, selected event types, real signature, duplicate delivery, and stale delivery must be evidenced.
- Decision: checkout and payment collection stay disabled until a sandbox payment and signed-webhook/idempotency receipt exist.

### Meta WhatsApp Cloud API

- [Getting started](https://developers.facebook.com/documentation/business-messaging/whatsapp/get-started) depends on a Meta business portfolio, WABA, registered business phone number, suitable approved template, and observed grants for `whatsapp_business_messaging` and `whatsapp_business_management` (`business_management` only where the chosen business-management endpoint requires it).
- [Webhooks](https://developers.facebook.com/documentation/business-messaging/whatsapp/webhooks/overview) require an HTTPS callback, verification token, subscribed WABA, and app-secret-based `X-Hub-Signature-256` validation. The customer-service window, consent, opt-out, retry, and delivery reconciliation need live configuration evidence.
- Decision: Atelier remains the authenticated operating surface and customer communication is manual. No automated WhatsApp delivery is enabled.

### Chat SDK

- [Chat SDK documentation](https://chat-sdk.dev/docs) is an implementation framework reference. Its official WhatsApp adapter is currently Beta; it does not confer Meta permissions, prove channel ownership, or prove provider delivery.
- A future adapter needs pinned package/adapter versions, an explicit Graph API version supported by both Meta and the adapter, provider credentials outside Git, least-privilege provider permissions, and inbound/outbound, duplicate, replay, attachment-size, and delivery-status conformance.
- Decision: the channel adapter remains disabled and proposal flows use local fixtures only.

### AliExpress Open Platform

- The [Open Platform portal](https://open.aliexpress.com) is authoritative for the exact API list granted to an approved developer/application. Required prerequisites are application approval, an app key/secret and authorized token outside Git, and applicable program/supplier eligibility.
- The eventual grant must explicitly cover `aliexpress.ds.product.get`, `aliexpress.ds.freight.query`, `aliexpress.ds.order.create`, `aliexpress.trade.ds.order.get`, and `aliexpress.ds.order.tracking.get`. Portal reachability proves none of approval, grants, rate limits, ordering eligibility, or a test facility.
- Decision: scraping is prohibited; Samantha performs sourcing, ordering, and tracking manually; `SupplierOrderWritePort` stays disabled.
