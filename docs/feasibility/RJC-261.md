# RJC-261 provider and compliance feasibility

Status: **Human Review / at risk**. G0 remains blocked. This is a dated official-document observation and safe-fallback decision, not provider onboarding evidence or legal advice.

## Official-source observations (retrieved 2026-08-01)

### Stripe

- [Testing](https://docs.stripe.com/testing) requires account sandbox access and a sandbox secret key. The intended integration must use a restricted key limited to its PaymentIntent resources. Test fixtures do not prove the account can create a PaymentIntent.
- [Webhook signature verification](https://docs.stripe.com/webhooks/signature) requires the unmodified raw request body, `Stripe-Signature` header, and endpoint-specific signing secret. A registered endpoint, selected event types, real signature, duplicate delivery, and stale delivery must be evidenced.
- Decision: checkout and payment collection stay disabled until a sandbox payment and signed-webhook/idempotency receipt exist.

### Meta WhatsApp Cloud API

- [Getting started](https://developers.facebook.com/docs/whatsapp/cloud-api/get-started) depends on a Meta business portfolio, WABA, registered business phone number, suitable approved template, and observed grants for `whatsapp_business_messaging` and `whatsapp_business_management` (`business_management` only where the chosen business-management endpoint requires it).
- [Webhooks](https://developers.facebook.com/docs/whatsapp/cloud-api/webhooks) require an HTTPS callback, verification token, subscribed WABA, and app-secret-based authenticity handling. The customer-service window, consent, opt-out, retry, and delivery reconciliation need live configuration evidence.
- Decision: Atelier remains the authenticated operating surface and customer communication is manual. No automated WhatsApp delivery is enabled.

### Chat SDK

- [Chat SDK documentation](https://chat-sdk.dev/docs) is an implementation framework reference. It does not confer Meta permissions, prove channel ownership, or prove provider delivery.
- A future adapter needs pinned package/adapter versions, provider credentials outside Git, least-privilege provider permissions, and inbound/outbound, duplicate, replay, attachment-size, and delivery-status conformance.
- Decision: the channel adapter remains disabled and proposal flows use local fixtures only.

### AliExpress Open Platform

- The [Open Platform portal](https://open.aliexpress.com) is authoritative for the exact API list granted to an approved developer/application. Required prerequisites are application approval, an app key/secret and authorized token outside Git, and applicable program/supplier eligibility.
- The eventual grant must explicitly cover listing and exact-SKU reads, fresh freight/quote data, order placement, order detail, and logistics tracking. Portal reachability proves none of approval, scopes, rate limits, ordering eligibility, or a test facility.
- Decision: scraping is prohibited; Samantha performs sourcing, ordering, and tracking manually; `SupplierOrderWritePort` stays disabled.
